```
node enablement/render-check.mjs
node enablement/check-site.mjs
```

- `render-pages.mjs` re-renders every page and refreshes the figure copies. `--out DIR` makes a dry run: a complete site, with site.css, site.js and _headers copied in.
- `render-check.mjs` takes `--verbose` to list every marked addition, and `--site DIR` to check a dry run instead of `enablement/site/`.
- `check-site.mjs` is lane E2's preflight, and it runs the text check too.

The headless checks and the mutation tests are scratch scripts (`p1/verify.mjs`, `p1/mutate.mjs`), outside the repository.
