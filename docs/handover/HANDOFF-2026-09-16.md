## 1. Mission, platform, North Star, and definition of done

### Mission and beneficiaries

Build a reusable, customer-neutral content/personalization Edge Affinity engine. Tapestry/Coach is one customer and a major source of requirements; the engine must not become a Coach-specific implementation. The remediation addresses security/privacy, authoritative state, relevant deterministic decisions, SDK experience, portable delivery, performance, and trustworthy measurement identified in the reconciled audit.

This is a TypeScript Cloudflare Workers application, not just a scoring library. `src/index.ts` mounts HTTP routes and coordinates scheduled/queue work. Hono handles routes/middleware. Cloudflare KV stores configuration and legacy session/profile projections; its eventual consistency is the reason it cannot simply be treated as transactional shopper authority. Durable Objects provide per-object serialized state, including shopper, statistics, recent decisions, regional trends, and rate limits. The browser SDK emits signals, manages identity/consent/session transport, and applies decisions. Static assets and demo/agent routes share this repository and must be governed at the customer boundary.

The main serving path spans `src/routes/content.ts`, `src/content/service.ts`, `src/content/decide.ts`, and `src/reflex/contentCompose.ts`. import { syncBuiltinESMExports } from 'node:module';
import { resolve } from 'node:path';
import { pathToFileURL } from 'node:url';
const cache = new Map(); let cacheBytes = 0;
for (const name of ['realpathSync', 'statSync']) {
  const original = fs[name], memo = new Map();
  fs[name] = function (...args) {
    const key = JSON.stringify(args);
    if (memo.has(key)) return memo.get(key);
    const result = original.apply(this, args); memo.set(key, result); return result;
  };
}
const read = fs.readFileSync;
fs.readFileSync = function (...args) {
  const key = JSON.stringify(args);
  if (cache.has(key)) return cache.get(key);
  const result = read.apply(this, args), size = typeof result === 'string' ? Buffer.byteLength(result) : result.length;
  if (size <= 33554432) {
    while (cacheBytes + size > 536870912 && cache.size) {
      const [first, item] = cache.entries().next().value; cache.delete(first);
      cacheBytes -= typeof item === 'string' ? Buffer.byteLength(item) : item.length;
    }
    cache.set(key, result); cacheBytes += size;
  }
  return result;
};

  };
