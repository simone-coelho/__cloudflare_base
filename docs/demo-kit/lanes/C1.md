# Lane C1: Compare that always works, as the demo kit's first module

**Opened 2026-10-01 by the lead.** Simone opened the hosted Vantage demo, pressed All beats, saw the tools row "compare: Capture · Compare · Fresh visitor · Streaming shopper", pressed Compare and nothing happened. She expects the page-level compares the older demos had: the original page beside the personalised page, and one page with a draggable seam showing half of each. The reusable widget exists: `public/meridian/compare.js` with `public/meridian/compare.css` (Meridian decision D8, ported from the Coach storefront's split-slider). Vantage did not use it; it built a decided-state table of its own and its Compare returns silently without a prior Capture (`public/vantage/vantage.js`, `openCompare`: `if (!state.capture) return;`), and the director's tool row never disables the button.

This lane fixes Vantage and, in doing so, creates the demo kit's first shared module. Every demo after Vantage uses it.

## The design (decided; do not reopen)

1. **The kit's compare widget** is `public/demo-kit/compare.js` and `public/demo-kit/compare.css`, ported from Meridian's with the same contract: no DOM or window access at import time; the overlay injected into `<body>` on first use; html2canvas loaded lazily from `/html2canvas.min.js` (present, 1.4.1); the stage never blank. Make the CSS self-contained: every `--cmp-*` token gets a default on the overlay root and may be overridden by the host page; the Meridian-only tokens it reads today (`--p-*`, `--paper`, `--sans`, `--serif`) become `--cmp-*` with defaults. Three segments in the bar: **Seam** (the draggable reveal, default), **Side by side** (both whole pages), and **What changed**, a third view whose content the host supplies through `openCompare(rootEl, { details })`, where `details` returns HTML. Keep zoom and the keyboard. Keep the "the press is the capture" behaviour as an option (`armPress(buttonEl)`) rather than a hard-wired `#btn-capture` id.
2. **A Before always exists.** Vantage captures a baseline frame automatically (a) after the homepage's first decided paint settles and after a phone page's first decided paint settles, in idle time, and (b) at the start of every performed beat, before the beat acts (where `captureProof(b, before)` records the decided state today). A manual Capture replaces the baseline. If Compare is pressed when no frame exists yet (the first paint still in flight), it must not do nothing: it opens the overlay with the message "No earlier frame yet: the first page is still being captured. Act, then Compare." and nothing else.
3. **Compare opens Seam by default**, tags "Before · hh:mm · where · who" and "Now · hh:mm · where · who", with Side by side one press away and What changed carrying Vantage's existing decided-state columns (the current `cmp-cols` table: lists, red rows where positions differ, strongest signals). The pixel views answer what the room saw; What changed answers why. The footer sentence stays: same page, same catalog, same buy box, same public prices.
4. **Fresh visitor works on both views.** Today it refuses on the homepage. New behaviour: baseline = her page as it is now; the fresh visitor's decided set (homepage or phone page, same region, no event sent) is rendered into the live DOM quietly, exactly as the streaming shopper's pages are today; the Now frame is captured; her page and address are restored from state with no re-ask; the overlay opens with tags "Her page" and "A fresh visitor, same region", and What changed shows the two columns as today. The streaming shopper does the same with its pixel frames.
5. **The director's tool row and the main bar**: Compare is always enabled; each Compare button's title says what the Before is ("Before: homepage at 14:02, Shopper A"). Capture's note stays.
6. **The page never ranks, never asserts, never reads anything new from the engine.** This lane is page-only.

### What changed, by file

- **`public/demo-kit/compare.js` (new): the kit's widget**, ported from `public/meridian/compare.js` (which is untouched). It keeps the same contract: no DOM or window access at import (checked by importing it in Node), the overlay injected into `<body>` on first use, html2canvas loaded lazily from `/html2canvas.min.js`, and the stage never blank. The bar has three views: **Seam** (the default), **Side by side**, and **What changed**, whose HTML the host supplies through `openCompare(rootEl, { details })` (a function of the two frames' `{ at, label, meta }`). Zoom and the keyboard are kept (← → Home End; Tab now cycles every control in the box, and Escape closes from anywhere). The press-is-the-capture behaviour is the option `armPress(target, { root, label, meta, when })` (an element or a selector), not a hard-wired id. Other exports: `captureBaseline` (with `label`, `meta`, `quiet`, `fresh`, `renderAfter`), `captureFrame` (a second shopper's frame), `baselineInfo`, `showWaiting`, `showMessage`, `isOpen`, `timings`, `configure({ motion, flip, freezeCss, ignore })`, `preload`. With no earlier frame, Compare opens on "No earlier frame yet: the first page is still being captured. Act, then Compare." and nothing else. What the port added beyond Meridian's file:
  - **The clone is the moment.** html2canvas clones the DOM synchronously inside the call; every capture resolves `.cloned` at that instant. Measured: a mutation made right after `.cloned` is absent from the frame (0 differing samples), while a frame of the mutated page differs in 167,115 samples. Meridian's retake-at-clone-height is gone: html2canvas measures the clone's own root, so a frame is always whole.
  - **`renderAfter`.** The clone is taken now; the render waits for the host's promise (bounded at 90 s), with the waiting clone's iframe out of layout. Vantage holds a beat's Before until the beat has landed.
  - **object-fit.** html2canvas 1.4.1 has no object-fit and stretched every cover or contain image. In the clone, each such image keeps its box and draws as a background of the same fit. The phones and the deal art now render true.
  - **Exact sameness.** "Nothing has changed" is decided by identical PNG bytes. A near-identical signature (a changed score in 11 px type) gets its own note, "Only small print has changed…", instead of being called the same page.
  - Frames are `toBlob` object URLs (older ones revoked), the seam handle and tags stay in view on a long page, the views are sized to the height left after the bar, sentence and hint, and the kit's own overlay never appears in a frame.
- **`public/demo-kit/compare.css` (new).** Self-contained: every `--cmp-*` token has its default on the overlay root at zero specificity (`:where(.cmp-back)`), so a host overrides it with one rule on `.cmp-back`. Meridian's tokens became `--cmp-paper`, `--cmp-ground`, `--cmp-ink`, `--cmp-dim`, `--cmp-line`, `--cmp-accent` (Meridian's `--cmp-blue`), `--cmp-display` (its `--cmp-serif`), `--cmp-sans` and `--cmp-mono`, plus the scrim, tag, warning, title-weight, radius and z-index tokens. `.cmp-busy` replaces Meridian's `#btn-capture.busy`.
- **`public/vantage/vantage.js`.** The kit is loaded with a dynamic `import()` on first use, and prefetched in idle time at boot; the page runs without it.
  - **A Before always exists.** (a) After each view's first decided paint for the visitor, in idle time, outside a performed beat (`afterDecidedPaint`, called from `refreshHome` and `refreshPhone`). (b) At the start of every performed beat, before it acts (`runBeat`); the beat waits for the clone only, and the render runs once it lands. A manual Capture replaces either (the main bar's Capture is armed; the director's Capture presses it).
  - Each frame keeps `{ where, who, snap }`. `snap` is `snapshotOfPage()`, which now also lists the site's own hero and four before anyone arrives, marked "(the site's own)".
  - **Compare** opens Seam, tagged "Before · hh:mm · where · who" and "Now · hh:mm · where · who", with the footer sentence kept. What changed carries the existing `cmp-cols` columns (red rows where positions differ, strongest signals). Compare pressed while a press is running opens a waiting box ("A press is still landing. Compare opens when it has.") and then the comparison.
  - **Every Compare button is always enabled**, its title naming the Before ("Before: homepage at 18:45, Shopper A"; "Before: none yet. Act, then Compare."). Capture's note keeps its wording.
  - **Fresh visitor** works on the homepage and the phone page: her page is the Before; the stranger's decided set (snapshot, plus her rail through `/sort`, no event) is drawn into the live page by the page's own renderers under the overlay (`paintQuietly`) and captured; then her page, scroll and address come back from state with no re-ask. Tags: "Her page" and "A fresh visitor, same region". The phone page's first-decision sentence no longer credits "her browsing" on a fresh visitor's frame.
  - **Streaming shopper** does the same with pixel frames: tags "Her page" and "The streaming shopper"; her restore is now one function, which also restores her scroll.
  - Supporting changes: `renderDeals(…, { rotate: false })` (her four repainted from state), and `askRail` split from `sortRail`. Every frame leaves out the out-of-page chrome and the hidden views, so the clone is the only cost of a press; none of them shape the site's layout, and no rule selects a view by position. The page's Escape and `E` handlers stand aside while the overlay is open, `go()` closes it, and the old overlay's code is removed.
- **`public/vantage/index.html`, `phone.html`.** Link `/demo-kit/compare.css` after `vantage.css`; Compare has no `disabled` and has a title; the old `#cmpBack` markup is removed (the kit injects its overlay).
- **`public/vantage/vantage.css`.** The old overlay's box rules are removed (their class names were the kit's); the kit's tokens are set in Vantage's red, black, Inter and JetBrains Mono; the What changed column styles are kept, plus `.cmp-cols-sub`.
- **`scripts/rehearse-vantage-dom.mjs`.** It reads the kit's overlay by computed visibility and real boxes, and a frame's pixels by loading its image. It adds a direct phone-page load (Compare pressed by an in-page observer the instant the status says ready, with 0 decided modules on the page) and the checks below. `--shots <dir>` saves the four views. Each press line now also prints the press's own time (go to landing), and the run ends with the capture measurements.
