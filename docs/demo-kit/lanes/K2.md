## Scope

Extract the page chassis out of `public/vantage/vantage.js` and `vantage.css` into `public/demo-kit/` as ES modules, and put Vantage back on top of them with no visible change.

| Module | Holds | Lifted from (`vantage.js`) |
|---|---|---|
| `transport.js` | api base, `X-Tenant` on every call, visitor minting, consent, events, ask and snapshot, receipts | the transport block (about lines 326–475) |
| `director.js` | the beats list, the runner, performed presses with the visible cursor, the keyboard, `?debug ?wait ?region ?fixtures` | the director and runner (about 2780–2830, 2992–3050) |
| `panels.js` | signals and meters, why these, cold start, report | about 1672–1970 |
| `deltas.js` | the before/now row and the moved chips, keyed by slot | about 871–973, 1227–1252 |
| `prove.js` | predict-then-prove from the published registry (constants and action weights read, never typed) | about 2869–2960 |
| `sheets.js` | the sheet mechanics, one overlay at a time | about 1437–1610 |
| `tokens.css` | the brand tokens with Vantage's values as the documented defaults: `--brand`, `--brand-deep`, `--accent`, `--ink`, `--paper`, `--line`, `--font`, `--mono`, radii, the director's own palette (`--m-*`) | `vantage.css` custom properties |
| `kit.css` | director, panels, rows, sheets and compare chrome, drawn from tokens only | `vantage.css` |
| `kit.js` | `createDemo(config)` wiring the modules; exposes the hooks the vertical needs | the bootstrap |

The vertical layer stays in `public/vantage/`: `index.html` and `phone.html`, `vantage.css` (token overrides and the vertical's own styles), `vantage.js` (renderers for cards, the buy box and module bodies; the `facts` object; the few beat verbs the kit lacks), the data files and the imagery.

**Beats become data.** `public/vantage/beats.json` holds Vantage's sixteen beats as `{ key, no, act, who, label, declare[], acts[], will[], line, run[] }`. Strings are templates over `facts` (`{{phone.name}}`, `{{storageStep.label}}`); `acts` name engine actions with attribute templates; `run` is a list of kit verbs (`open`, `click`, `select`, `wait`, `custom`, `assert`, `focus`) with one escape hatch, `call: <name>`, into the vertical's functions. Every beat that needs the escape hatch is listed in the report with the reason; the goal is as few as possible, and the vocabulary grows before a beat goes back into code.
