# Lane K1: the server side of the demo kit

**Opened 2026-10-01 by the lead.** Design: [Demo-Kit-Design.md](../Demo-Kit-Design.md) §2.1 and §4. The framework lane's map names the seams with line numbers: [lg-framework-map.md](../../lg/research/lg-framework-map.md) §1.

## Scope

Extract the demo route factories from Vantage without changing any behaviour.

1. `src/demos/kit/actionRoutes.ts`: `demoActionRoutes({ tenant, operator, beats, reset, reportSlots, asserted, dispatch })` returning the Hono routes `/beat`, `/reset`, `/receipt`, `/report` exactly as `src/routes/vantage.ts` serves them today. The pure helpers (`noteOf`, `publishedDocument`, `ownDecisionId` with the tenant prefix as a parameter, `receiptOf`, `assertedContextOf` with the asserted-intent set as a parameter, `assertedOf`, `reportTooLarge`) move to `src/demos/kit/helpers.ts` unchanged in logic.
2. `src/demos/kit/coldStartRoutes.ts`: `demoColdStartRoutes({ tenant, vocabulary, sentence, markerKey, ... })` from `src/routes/vantageColdStart.ts`; `resolveRegion`, `censusFor`, `estimateOf` are already tenant-free and move as they are.
3. `src/demos/vantage.config.ts`: Vantage's constants (`VANTAGE_TENANT`, `VANTAGE_BEATS`, `VANTAGE_RESET`, `VANTAGE_REPORT_SLOTS`, the operator, the asserted intents, the seed vocabulary, the marker key, the sentence) in one place.
4. `src/routes/vantage.ts` and `src/routes/vantageColdStart.ts` become thin: they build from the config through the factories and **keep exporting the same names** (`vantageRoutes`, the constants, the helpers re-exported) so `src/index.ts` and every existing test import still resolve. If `src/index.ts` needs no edit, do not edit it.
5. Tests: the existing `src/routes/vantage.test.ts` and `src/routes/vantageColdStart.test.ts` keep passing **unmodified** (they are the regression gate). Add `src/demos/kit/actionRoutes.test.ts` and `coldStartRoutes.test.ts` that exercise the factories with a second, fictional tenant config (prefix handling in `ownDecisionId`, the closed beat list, the asserted set, the report slots), so the factories are proven general and not only Vantage-shaped.

Out of scope: `src/routes/topOffers.ts` and the QVC worker; any `public/**`; any `scripts/**`; any engine file under `src/content`, `src/reflex`, `src/learn`, `src/identity`. If the extraction seems to need an engine change, stop at that point and report it.

### Deviations, with reasons

- **I used port 9131, not 9111.** On the Windows side, 9111 is held by a static server (`node serve.mjs <repo>/public 9111`, started 2026-09-30 at 18:31 from another session's scratchpad). WSL shares the loopback, so wrangler could not bind the port. The server is not mine, so I did not stop it. It is probably the retired L2/L4 scratch server, and the owner may want it stopped. No brief assigns 9131.
- **The seed rewrites Lane C1's generated files.** `seed-vantage.mjs` always writes `public/vantage/catalog.json` and `beats/*.json`. I snapshotted those 19 files first. Straight after the seed, I restored the four it had changed (`anchor.json`, `open-catalog`, `11-two-weeks-pass`, `12-black-friday`), but only where they still held my seed's bytes. All 19 match the snapshot, so they were exposed for under a minute. The suite then ran on the committed documents (anchor 14:34Z), which is consistent: every window is a whole number of days, so open and closed states match a fresh anchor until 2026-10-02T14:34Z, and the suite resets from those files before its first decision.
- The suite read C1's in-progress page files: `index.html`, `phone.html`, `vantage.css` and `vantage.js` were modified in the tree at the time. Every page check passed.
- My server was stopped cleanly afterwards. The gitignored `.wrangler/state-k1` remains.

### For the reviewer (pre-existing, kept as is)

- `assertedContextOf` strips its prefix with `/^ctx./`, and the dot is unescaped, so any single character after `ctx` is accepted as the separator. The value is still checked against the closed set.
- `/receipt` does not compare `X-Tenant` with the demo's tenant. The id prefix and the owner check on the record guard it, and on a single-tenant demo worker the shopper check cannot resolve another tenant anyway.
