## 4. Findings and residuals

1. **`TREND_ROLLUP_TENANTS` is not read by the code (F2 finding 6 was a misreading).** The hourly cron rolls up every tenant the worker provisions, `tenantConfig(env).provisioned` (`src/index.ts:260-261`, `:316-325`). The variable's only mentions in `src/` are its declaration (`src/types/env.ts:31`) and a test that sets it to `'obsolete,acme'` and asserts nothing named in it is touched (`src/index.api-boundary.test.ts:660`, `:3383-3389`). So the hosted roll-up already covered whatever the worker's `TENANTS` secret provisions, `vantage` included. The regeneration was done as ordered: inert, and consistent with `AGENTS.md` and `BOOTSTRAP.md`.
2. **The ordered builder command drops `--dev-port 9110`.** Without it `[dev]` falls back to `wrangler.toml`'s 9100, the shared demo's local port. I kept `--dev-port 9110` (the existing generated header had it) in the file and in the resume. `AGENTS.md:62` and `docs/demos/BOOTSTRAP.md:329` carry the command without it (lead's files). `scripts/build-demo-worker-config.mjs:17-20` still says "Vantage sets none" (not my file).
3. **Publish-time registry membership is not checked.** The learn validator has no registry in hand (the publish route runs `kind.validate` alone, `src/routes/content.ts:367`), so a well-formed name the tenant's registry lacks is accepted and matches nothing at decision time. Refusing it at publish needs a registry read beside `priorUnitRefusals` in `src/routes/content.ts`, outside this grant: named, not built. Vantage's own seed refuses such a name before publishing.
4. **The Arrival panel still lists every dimension the region holds** (`src/routes/vantageColdStart.ts:227`, `share` and `leaders` from `trend.snapshot.share`). After a walkthrough it shows intent, lines, perk and content-type values the prior no longer blends. One change there (`sharesWithin(trend.snapshot.share, settings.dimensions)` for both; `regionalSettings` already returns the list) would make the panel show only what is blended. Not in this grant.
5. **`RESUME-vantage.md`'s "Every walkthrough leaves its touches in its own state" bullet** says one intent or lines touch takes beat 1 off the ad; after this lane that no longer holds (§3). Reseeding the presenter's state after suites stays good practice for the small drift in the allowed dimensions. Prose, so left to the lead (this lane changed commands only).
