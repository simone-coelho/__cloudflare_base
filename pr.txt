# Recommendations Documentation

> Documentation for Recommendations

## Guides
- [Product Recommendations](https://docs.developers.optimizely.com/recommendations/v1.1.0-product-recommendations/docs/personalization.md): Describes getting started with Recommendations and some of the common features.

- [Native integrations](https://docs.developers.optimizely.com/recommendations/v1.1.0-product-recommendations/docs/native-integrations.md): Describes native integrations for the Optimizely Recommendations product suite, which are used when implementing product recommendations and personalized search results (legacy).
- [Cancel orders](https://docs.developers.optimizely.com/recommendations/v1.1.0-product-recommendations/docs/order-cancellations.md): Describes how to manage order cancellations when you use the recommendations service as part of the Optimizely Recommendations product suite.
- [Recommendations UI in CMS](https://docs.developers.optimizely.com/recommendations/v1.1.0-product-recommendations/docs/personalization-ui.md): Add the Recommendations Portal to the global navigation menu in the Optimizely Content Management System (CMS) user interface (UI).
- [Server-to-Server API](https://docs.developers.optimizely.com/recommendations/v1.1.0-product-recommendations/docs/server-to-server-api.md): Describes the Server-to-Server API used for integrating Optimizely recommendations features.

- [Checkout page](https://docs.developers.optimizely.com/recommendations/v1.1.0-product-recommendations/docs/checkout-page-javascript-api.md): The checkout page is similar to the basket page tracking request with additional properties including  subtotal, shipping, and total value of the basket.
- [Home page](https://docs.developers.optimizely.com/recommendations/v1.1.0-product-recommendations/docs/home-page.md): Describes how to configure a tracking request on the Home page.
- [Order page](https://docs.developers.optimizely.com/recommendations/v1.1.0-product-recommendations/docs/order-page-javascript-api.md): Similar to the checkout page, the order confirmation page must contain all items in the order, currency, subtotal, shipping and total for the order. The page should also include the order number.
- [Other page](https://docs.developers.optimizely.com/recommendations/v1.1.0-product-recommendations/docs/other-page.md): Describes how to configure a tracking request on a page not previously mentioned.
- [Product page](https://docs.developers.optimizely.com/recommendations/v1.1.0-product-recommendations/docs/product-page-javascript-api.md): You can track a product page by providing the product's reference code.
- [Search results page](https://docs.developers.optimizely.com/recommendations/v1.1.0-product-recommendations/docs/search-results-page.md): Describes how to configure a tracking request on the search results page.
- [Wishlist page](https://docs.developers.optimizely.com/recommendations/v1.1.0-product-recommendations/docs/wishlist-page.md): Describes how to configure a tracking request on a wish list page.
- [Variant tracking](https://docs.developers.optimizely.com/recommendations/v1.1.0-product-recommendations/docs/variant-tracking.md): You can track product variants on the basket, checkout, and order pages by adding an optional variant parameter for each product (see the appropriate page tracking section for more details).
- [Link to a specific basket](https://docs.developers.optimizely.com/recommendations/v1.1.0-product-recommendations/docs/link-to-a-specific-basket-javascript-api.md): Shows how to set up abandoned basket trigger campaigns to link to a particular basket with the abandoned products.
- [Response message](https://docs.developers.optimizely.com/recommendations/v1.1.0-product-recommendations/docs/response-message-1.md): Shows response messages.

The page should also include the order number.
- [Other page](https://docs.developers.optimizely.com/recommendations/v1.1.0-product-recommendations/docs/other-page-javascript-api.md): If the page the user is served does not match any tracking types in the previous sections, an other tracking request must be sent.
- [Product page](https://docs.developers.optimizely.com/recommendations/v1.1.0-product-recommendations/docs/product-page.md): Tracked by providing the reference code of the product.
