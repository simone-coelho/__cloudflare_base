📡 API Endpoints

GET /health - Health check and service status
POST /track/event - Track custom events
GET /pixel/track/:id - Track email pixel
POST /optimizely/decisions - Get experiment decisions
POST /cdp/profile - Get user profile
POST /auth/login - Authenticate user
